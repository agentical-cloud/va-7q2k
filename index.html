Datenschutzerklärung für die Anwendung „Victor“

Stand: 11. Oktober 2026

Victor ist ein persönlicher KI-Assistent, den die AGENTICAL GmbH für einzelne Kundinnen und Kunden betreibt. Jede Kundin und jeder Kunde hat eine eigene Installation auf einem eigenen Server in Deutschland. Diese Erklärung beschreibt, wie Victor mit Daten aus einem Google-Konto umgeht, wenn die Nutzerin oder der Nutzer Victor den Zugriff auf den eigenen Google Kalender erlaubt.

2. Auf welche Google-Daten Victor zugreift

Victor greift ausschließlich auf den Google Kalender des Kontos zu, für das die Nutzerin oder der Nutzer die Freigabe selbst erteilt hat. Der Zugriff umfasst das Lesen, Anlegen, Ändern und Löschen von Kalendereinträgen. Auf andere Google-Dienste (zum Beispiel Gmail, Drive oder Kontakte) greift Victor mit dieser Freigabe nicht zu.

3. Wofür die Daten verwendet werden

Die Kalenderdaten werden nur verwendet, um Aufträge der Nutzerin oder des Nutzers auszuführen, zum Beispiel Termine anzuzeigen, einzutragen, zu verschieben oder an Termine zu erinnern. Die Daten werden nicht für Werbung verwendet, nicht verkauft und nicht für eigene Zwecke der AGENTICAL GmbH ausgewertet.

4. Wo die Daten verarbeitet und gespeichert werden

  • Victor läuft auf einem eigenen Server der jeweiligen Kundin oder des jeweiligen Kunden in einem Rechenzentrum in Deutschland.
  • Die Zugriffsfreigabe für Google (ein sogenanntes Token) wird zugriffsgeschützt auf diesem Server gespeichert.
  • Kalenderinhalte werden nicht vollständig kopiert. Inhalte, die für eine Anfrage abgerufen wurden, können Teil des Gesprächsverlaufs mit Victor sein und werden dann mit diesem auf dem Server gespeichert.

5. Weitergabe an Dritte

Um eine Anfrage zu beantworten, übermittelt Victor die dafür nötigen Inhalte an den Anbieter des verwendeten KI-Sprachmodells (derzeit OpenAI, als Ersatz Anthropic). Das können auch Inhalte aus Kalendereinträgen sein, wenn die Anfrage sie betrifft. Der Server wird bei der Hetzner Online GmbH betrieben. Eine darüber hinausgehende Weitergabe findet nicht statt, außer wenn eine gesetzliche Pflicht dazu besteht.

6. Einhaltung der Google-Richtlinien

Die Verwendung von Informationen, die Victor über Google-Schnittstellen erhält, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

7. Speicherdauer und Widerruf

Die Freigabe gilt, bis sie widerrufen wird. Sie kann jederzeit im eigenen Google-Konto unter myaccount.google.com/permissions entzogen werden. Victor hat danach keinen Zugriff mehr auf den Kalender. Auf Wunsch löscht die AGENTICAL GmbH die auf dem Server gespeicherte Freigabe und die gespeicherten Gesprächsverläufe.

Die Verarbeitung erfolgt zur Erfüllung des Vertrags über die Bereitstellung des Assistenten (Art. 6 Abs. 1 Buchstabe b DSGVO) und auf Grundlage der im Google-Konto erteilten Einwilligung (Art. 6 Abs. 1 Buchstabe a DSGVO).
