Datenschutzerklärung für die Anwendung „Victor“

Stand: 11. Oktober 2026

Victor ist ein persönlicher KI-Assistent, den die AGENTICAL GmbH für einzelne Kundinnen und Kunden betreibt. Jede Kundin und jeder Kunde hat eine eigene Installation auf einem eigenen Server in Deutschland. Diese Erklärung beschreibt, wie Victor mit Daten aus einem Google-Konto umgeht, wenn die Nutzerin oder der Nutzer Victor den Zugriff auf den eigenen Google Kalender und das eigene Gmail-Postfach erlaubt.

2. Auf welche Google-Daten Victor zugreift

Victor greift ausschließlich auf das Konto zu, für das die Nutzerin oder der Nutzer die Freigabe selbst erteilt hat, und dort nur auf diese zwei Dienste:

  • Google Kalender: Lesen, Anlegen, Ändern und Löschen von Kalendereinträgen.
  • Gmail: Lesen von E-Mails, Erstellen von Entwürfen, Senden von E-Mails sowie Bearbeiten von E-Mails (zum Beispiel als gelesen markieren, mit Labels versehen, archivieren oder in den Papierkorb legen).

Auf andere Google-Dienste (zum Beispiel Drive oder Kontakte) greift Victor mit dieser Freigabe nicht zu.

3. Wofür die Daten verwendet werden

Die Kalender- und E-Mail-Daten werden nur verwendet, um Aufträge der Nutzerin oder des Nutzers auszuführen, zum Beispiel Termine anzuzeigen oder einzutragen, E-Mails zusammenzufassen, Antworten vorzubereiten oder auf Anweisung zu senden. Die Daten werden nicht für Werbung verwendet, nicht verkauft und nicht für eigene Zwecke der AGENTICAL GmbH ausgewertet.

4. Wo die Daten verarbeitet und gespeichert werden

  • Victor läuft auf einem eigenen Server der jeweiligen Kundin oder des jeweiligen Kunden in einem Rechenzentrum in Deutschland.
  • Die Zugriffsfreigabe für Google (ein sogenanntes Token) wird zugriffsgeschützt auf diesem Server gespeichert.
  • Kalender und Postfach werden nicht vollständig kopiert. Inhalte, die für eine Anfrage abgerufen wurden, können Teil des Gesprächsverlaufs mit Victor sein und werden dann mit diesem auf dem Server gespeichert.

5. Weitergabe an Dritte

Um eine Anfrage zu beantworten, übermittelt Victor die dafür nötigen Inhalte an den Anbieter des verwendeten KI-Sprachmodells (derzeit OpenAI, als Ersatz Anthropic). Das können auch Inhalte aus Kalendereinträgen und E-Mails sein, wenn die Anfrage sie betrifft. Der Server wird bei der Hetzner Online GmbH betrieben. Eine darüber hinausgehende Weitergabe findet nicht statt, außer wenn eine gesetzliche Pflicht dazu besteht.

6. Einhaltung der Google-Richtlinien

Die Verwendung von Informationen, die Victor über Google-Schnittstellen erhält, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

7. Speicherdauer und Widerruf

Die Freigabe gilt, bis sie widerrufen wird. Sie kann jederzeit im eigenen Google-Konto unter myaccount.google.com/permissions entzogen werden. Victor hat danach keinen Zugriff mehr auf Kalender und Postfach. Auf Wunsch löscht die AGENTICAL GmbH die auf dem Server gespeicherte Freigabe und die gespeicherten Gesprächsverläufe.
